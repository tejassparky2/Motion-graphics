# Midnight with Manya: channel setup (about 10 minutes)

Files in this folder: `avatar.png` (profile picture, 800 x 800) and `banner.png` (2560 x 1440; the name and text sit
in the centre strip every device shows).

## 1. The Gmail (you do this: Google verifies it with your phone)
1. Go to accounts.google.com/signup and choose "For my personal use".
2. Name: First name `Midnight`, last name `with Manya` (keeps your own name off the channel).
3. Username, try in this order: `midnightwithmanya`, `midnightwithmanya.stories`, `manyaatmidnight`.
4. Recovery phone and recovery email: your own.
5. Straight after: myaccount.google.com, then Security, then turn on 2-Step Verification.

Keep the password to yourself (a password manager is best). Nobody else needs it, me included.

## 2. The YouTube channel
1. Signed in with the new Gmail, open youtube.com, tap the profile picture, then "Create a channel".
2. Name: `Midnight with Manya`. Handle: `@MidnightWithManya` (nobody had it on 25 Oct 2026; claim it now).
3. Upload `avatar.png` as the picture and `banner.png` as the banner.
4. YouTube Studio, then Customization, then Basic info: paste the description below; contact email = the new Gmail.
5. Studio, then Settings, then Channel:
   - Basic info: country India; paste the keywords below.
   - Advanced settings: Audience: **"No, set this channel as not made for kids."** This one matters: a channel
     set as made for kids has comments switched off, and the A/B vote happens in the comments.
   - Feature eligibility: verify your phone number.
6. Settings, then Upload defaults: category Film & Animation; language English; tags from the keywords below.

## Channel description (paste as is)
```
Hi, I'm Manya. Every story here happens to YOU: the elevator that stops on a floor your building doesn't have, the last bus that isn't in service, the radio that calls for help in your own voice.

Each story stops at a choice. Comment A or B. The answer most of you pick decides what happens next.

Original horror stories in 2D animation. Suspense, not gore.

Manya is a fictional storyteller, and the stories are fiction. Narration uses synthetic voices.
```

## Keywords (paste as is)
```
horror stories, interactive horror, you decide, choose your ending, scary stories, animated horror, 2d animation, creepy stories, horror shorts, comment a or b, Midnight with Manya
```

## Posting the three episodes
- Each episode has its own upload sheet (title, description, hashtags, tags, pinned comment):
  `out/horror/tower9_2d_metadata.md`, `out/horror/last_stop_2d_metadata.md`, `out/horror/floor13_2d_metadata.md`.
- Suggested order: Tower 9 first (your favourite), then Last Stop, then Floor 13, so each vote has time to build.
- Pin the pinned comment right after posting; the vote starts there.
- The upload form's "altered or synthetic content" question is for realistic footage that could be mistaken for
  real people or events. Clearly animated fiction like these doesn't need it, and the channel description already
  says the voices are synthetic.
