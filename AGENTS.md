# Guide for AI coding agents (Codex, Gemini CLI, Cursor, Claude Code, …)

This repo makes the **Interestingly Strange** YouTube Shorts: 45-second, 720×1280, 30 fps, hand-drawn-looking 2D
cartoons narrated by the Kokoro voice `am_fenrir` (the owner's cloned voice is available with `NARRATOR_ENGINE=clone`). Nothing is generated by a video AI: every frame is drawn
by Python code (pycairo), and the voice is synthesized per sentence and checked with Whisper. Quality comes from that
pipeline plus the checks below, so follow it exactly.

**Read `CLAUDE.md` first.** Its rules (narration, paradox clarity, channel basics) apply to every agent, not only Claude.

## 1. Setup (once)

```bash
python3.11 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt            # pycairo, numpy, kokoro, faster-whisper, imageio-ffmpeg, …
# The owner's cloned voice runs in its own venv (torch is heavy):
python3.11 -m venv ~/.venv-clone && ~/.venv-clone/bin/pip install chatterbox-tts==0.1.7 soundfile
export CLONE_PYTHON=~/.venv-clone/bin/python   # motion/voice.py calls tools/clone_tts.py with it
```

On a CPU, one full render takes 15–30 minutes. A CUDA GPU makes the voice step much faster.

## 2. How one video is built

Each video is **one file**: `videos/<name>.py`. Copy a recent one as the template:
`videos/machiavelli_feared.py` (clever words from history) or `videos/spotlight_effect.py` (researchers found).

| Part | What it is |
|---|---|
| Docstring | The source and the real quoted wording, with citations. Facts are checked before writing the script. |
| `SCRIPT` | A list of lines: `dict(id="m1", scene="hook", text="…")`. Optional fields: `pace=0.95` (slower), `speaker="oldman"` (a character voice), `speaker_from="word"` (narrator hands over to the character at that word). |
| `[spoken\|shown]` | Says one thing and shows another in the captions, e.g. `[fifteen thirteen,\|1513,]`. |
| `METADATA` | The upload sheet: title, alt titles, description, hashtags, tags, pinned comment. |
| `scene_<name>(cr, t, tl)` | Draws one scene for time `t`. Every animation is keyed to the **moment a word is spoken**: `tl.at("m3", "feared")`. The key is a substring of the spoken token *including punctuation* (`"hated?"`, `"2018,"`). |
| `draw(cr, t, tl)` | Picks the scene for the current line and adds captions. |

Shared building blocks:
- `motion/engine.py`: wobbly hand-drawn shapes (`shape`, `blob`, `line`), text (`write`), easing (`pop`, `ease_out`, `seg`).
- `motion/characters.py`: `CAST` and `person(...)`. Add a new costume as a `CAST` entry (e.g. Alexander, Franklin).
- `motion/kit.py`: `hl` (headline at y=215), `stamp`, `whip` (transition), `confetti`, camera helpers.
- `motion/story.py`: `bg` (sky, ground and close camera), `card`, `scroll` (quotes), `tag`, `buttons` (end question).
- `motion/timeline.py`: sentence takes and pauses (`SENTENCE_TAKES`, `STOP_PAUSE`, `BEAT_GAP`), `clear_dialogue` for riddles. Don't turn these off.
- `motion/voice.py`: `CLONE_SAY` respellings for words the clone voice says badly ("Plutarch" → "Ploo-tark").

### Screen layout (the most common mistake)

- With `story.bg`, the camera focus lands at screen y = 640: **screen y = 640 + zoom × (world y − focus y)**.
  With `kit.enter_world`, the anchor is (360, 780).
- Captions sit at screen y ≈ 915. Faces, cards and charts must stay **above y ≈ 860** and fully inside 0–720 px.
- The headline (`hl`) sits at y = 215. Use the close camera (`CLOSE = (1.5, 360, 800)`) so people fill the frame: if
  everything looks small, the camera is too far.
- The Kalam font has no arrow glyphs (➜ →): write words instead.

## 3. Workflow for every video

1. **Research.** Use real, sourced facts and quotes. Say "often credited to" when the source is unknown. Leave out disputed claims.
2. **Script, then wait.** Send the owner the script (lines, what's on screen, title, sources) and render only after they
   approve or edit it. Keep their wording.
   **Writing it:** Hook with the surprising claim in line 1. One idea per sentence, full stops everywhere, and a visual change about every second.
   End on a question that invites comments. Aim for 40–50 s.
3. **Fast preview** (Kokoro voice, a few seconds):
   `NARRATOR_ENGINE=kokoro python render.py --video NAME --sheet 1 --out build/NAME_sheet.png` gives a contact sheet of
   frames. **Look at it**: check nothing overlaps the captions, nothing is cut off and nothing is too small.
   Use `--still 12.5` for one frame.
4. **Full render and check:** `tools/render_check.sh NAME`. This renders in the default narrator voice, then:
   - `tools/verify.py` (Whisper small): overall word match, pace, and no encoder or metadata tags in the file.
   - `tools/audit.py` (Whisper **medium**): transcribes every line separately and prints any line where words were misheard.
5. **Fix every real mishearing** by rewording the line (or adding a `CLONE_SAY` respelling), then render again.
   Number formats ("1960s" for "nineteen sixties") and true homophones ("sun" and "son") are fine.
   The take cache in `build/clone_tts/` is keyed on the caption text. After changing only a respelling, delete that sentence's
   cached `.wav`, or the old take is reused.
6. **Outputs:** `out/NAME.mp4`, `out/NAME_preview.mp4` and `out/NAME_metadata.md` (the upload sheet). Commit them.

## 4. Never

- Never clone any voice other than the owner's (`assets/voice/owner_prompt*.wav`).
- Never strip other parties' provenance watermarks (Chatterbox's Perth watermark, SynthID, C2PA) and never add metadata or encoder tags.
- Never phrase anything as a call to violence. Quote people's real, sourced words.
- Never make doctor or "Body Facts" videos on this branch: that channel has its own branch.
